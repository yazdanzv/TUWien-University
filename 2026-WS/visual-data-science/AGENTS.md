# Visual Data Science — Course Instructions

- Emphasize exploratory data analysis, careful preprocessing, and defensible
  interpretation before presentation.
- Prefer Python, pandas, Plotly, and course-approved visualization libraries;
  use alternatives only when the task benefits from them.
- Design interactive dashboards and applications around clear user tasks,
  useful interaction, and visualization usability.
- Build executable applications when required and keep environments, data
  transformations, parameters, and random seeds reproducible.
- Distinguish exploratory observations from supported conclusions and follow
  assignment-specific technology constraints.
