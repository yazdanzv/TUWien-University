# Machine Learning — Course Instructions

- Prefer Python, NumPy, pandas, and scikit-learn unless the assignment specifies
  another stack.
- Explain supervised and unsupervised methods with the necessary mathematical
  and algorithmic reasoning.
- Use appropriate train/validation/test separation, baselines, metrics,
  cross-validation, and uncertainty reporting.
- Prevent data leakage by fitting preprocessing and feature selection only on
  training data, preferably through pipelines.
- Perform hyperparameter optimization within the validation procedure and keep
  experiments reproducible with recorded configurations and seeds.
- Report only results produced by executed experiments and honor
  assignment-specific evaluation rules.
